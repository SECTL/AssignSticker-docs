# 欢迎来到 AssignSticker！

欢迎使用 AssignSticker！
这是一个基于Pywebview开发的作业看板应用程序，用于将作业显示到班级一体机上。

### ✨亮点

 - 👉支持 **模版布置作业** ：让作业布置更高效
 - 👉支持 **富文本作业编辑** ：突出重点，使作业更易读
 - 👉 支持 **作业自由缩放** ：让后排的学生也能清晰地看到作业内容
 - 👉 支持 **国产Linux操作系统** ：AssignSticker 支持**国产搭载了UOS、DEEPIN、银河麒麟等Linux操作系统**的希沃/鸿合一体机设备


更多亮点，等你来体验！
